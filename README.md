# Evan's Blog

欢迎来到我的个人博客！这里记录了我的技术学习、项目实践和生活感悟。希望通过这个博客与大家分享知识、交流想法。

## 博客简介

- **博客地址**: [https://evan-devcode.github.io/my-blog/](https://evan-devcode.github.io/my-blog/)
- **主题**: 使用 [Hugo](https://gohugo.io) 静态网站生成器，主题为 [Hugo Theme Stack](https://github.com/CaiJimmy/hugo-theme-stack)。
- **语言**: 主要使用中文（`zh-cn`），偶尔会有英文内容。

## 博客内容

我的博客主要涵盖以下内容：

- **技术笔记**: 编程语言、框架、工具的使用心得和教程。
- **项目实践**: 个人项目的开发过程和经验总结。
- **生活随笔**: 学习、工作和生活中的思考与感悟。
